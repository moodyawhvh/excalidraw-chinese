## 项目简介

Excalidraw 是一个开源的虚拟手绘风格白板（virtual whiteboard），支持多人协作与端到端加密。

在线编辑器：<https://excalidraw.com> ｜ 博客：<https://plus.excalidraw.com/blog> ｜ 官方文档：<https://docs.excalidraw.com> ｜ 商业版 Excalidraw+：<https://plus.excalidraw.com>

你可以用它画出漂亮的手绘风格示意图、线框图（wireframe），或者任何你想画的东西。

## 特性

Excalidraw 编辑器（npm 包）支持：

- 💯 免费且开源
- 🎨 基于画布的无限白板
- ✍️ 手绘风格
- 🌓 深色模式
- 🏗️ 可定制
- 📷 支持图片
- 😀 支持图形素材库
- 🌐 支持多语言本地化（i18n）
- 🖼️ 可导出为 PNG、SVG 以及复制到剪贴板
- 💾 开放格式——绘图可导出为 `.excalidraw` JSON 文件
- ⚒️ 丰富的工具：矩形、圆、菱形、箭头、直线、自由绘制、橡皮擦……
- ➡️ 箭头绑定与带标签的箭头
- 🔙 撤销 / 重做
- 🔍 支持缩放与平移

## Excalidraw.com

托管在 [excalidraw.com](https://excalidraw.com) 上的应用是"你能用 Excalidraw 做出什么"的最小示例。它的[源代码](https://github.com/excalidraw/excalidraw/tree/master/excalidraw-app)也包含在本仓库中，该应用具备以下功能：

- 📡 支持 PWA（可离线使用）
- 🤼 实时协作
- 🔒 端到端加密
- 💾 本地优先（自动保存到浏览器）
- 🔗 可分享链接（导出为只读链接分享给他人）

未来这些功能会以"即插即用"插件的形式加入 npm 包。

## 快速开始

**注意：** 以下说明面向"把 Excalidraw 作为 [npm 包](https://www.npmjs.com/package/@excalidraw/excalidraw)集成到自己的应用"的场景。如果想在本地运行本仓库进行开发，请参阅官方[开发指南](https://docs.excalidraw.com/docs/introduction/development)。

使用 `npm` 或 `yarn` 安装依赖包：

```bash
npm install react react-dom @excalidraw/excalidraw
# or
yarn add react react-dom @excalidraw/excalidraw
```

更多细节请查阅[文档](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/installation)。
