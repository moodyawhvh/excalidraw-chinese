# 安装

`@excalidraw/mermaid-to-excalidraw` 已发布到 npm。[excalidraw](https://excalidraw.com) 内部就用这个库把 mermaid 语法转换成 Excalidraw 图形。

使用 `npm`

```bash
npm install @excalidraw/mermaid-to-excalidraw
```

使用 `yarn`

```bash
yarn add @excalidraw/mermaid-to-excalidraw
```

## 用法

库安装完成后即可直接使用。

```js
import { parseMermaidToExcalidraw } from "@excalidraw/mermaid-to-excalidraw";
import { convertToExcalidrawElements}  from "@excalidraw/excalidraw"

try {
  const { elements, files } = await parseMermaid(diagramDefinition, {
    fontSize: DEFAULT_FONT_SIZE,
  });
  // 目前解析器返回的元素是"skeleton(骨架)"格式,
  // 需要先转换成完整的 excalidraw 元素
  const excalidrawElements = convertToExcalidrawElements(elements);

  // 在 Excalidraw 中渲染 elements 和 files
} catch (e) {
  // 错误处理
}
```
