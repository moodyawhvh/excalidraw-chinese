# 开发

本页内容与 `@excalidraw/mermaid-to-excalidraw` 包本身的开发相关。

## 本地环境搭建

按下面的步骤在本地搭好这个库 👇🏼

### 克隆仓库

前往 [@excalidraw/mermaid-to-excalidraw](https://github.com/excalidraw/mermaid-to-excalidraw),把仓库克隆到本地。


```bash
git clone git@github.com:excalidraw/mermaid-to-excalidraw.git
```

### 安装依赖

使用 `npm`

```bash
npm install @excalidraw/mermaid-to-excalidraw
```

使用 `yarn`

```bash
yarn add @excalidraw/mermaid-to-excalidraw
```

### 启动演练场(playground)服务

```bash
yarn start
```

该命令会在 `1234` 端口启动演练场服务,然后你就可以在 playground 里随便玩了。

## 创建测试版本

我们很快会支持直接在 GitHub PR 下评论来创建 release;在此之前,请按下面的步骤手动创建:

1. 构建产物

```bash
yarn build
```

该命令会生成 dist 文件夹,接下来要发布的就是它。

2. 发布库

更新 [package.json](https://github.com/excalidraw/mermaid-to-excalidraw/blob/master/package.json) 中的包名和版本号,然后运行以下命令发布

```bash
yarn publish
```

至此,你的测试版本就发布成功了 🎉
