# 常量(Constants)

### FONT_FAMILY

**用法**

```js
import { FONT_FAMILY } from "@excalidraw/excalidraw";
```

`FONT_FAMILY` 包含 `Excalidraw` 用到的所有字体族。默认字体族如下:

| 字体族 | 说明 |
| ----------- | ---------------------- |
| `Excalifont` | `手绘(Hand-drawn)`字体 |
| `Nunito` | `常规(Normal)`字体 |
| `Comic Shanns` | `代码(Code)`字体 |

默认选中 `FONT_FAMILY.Excalifont`,除非通过 `initialData.appState.currentItemFontFamily` 覆盖。

### THEME

**用法**

```js
import { THEME } from "@excalidraw/excalidraw";
```

`THEME` 包含 `Excalidraw` 支持的全部主题,如下所示

| 主题 | 说明 |
| ------- | ----------------- |
| `LIGHT` | `浅色(light)`主题 |
| `DARK` | `深色(Dark)`主题 |

默认为 `THEME.LIGHT`,除非通过 `initialData.appState.theme` 传入。

### MIME_TYPES

[`MIME_TYPES`](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/constants.ts#L101) 包含 `Excalidraw` 支持的所有 MIME 类型。

**用法**

```js
import { MIME_TYPES } from "@excalidraw/excalidraw";
```
