# API

目前 **API** 分为三大类 👇

- [Props](/docs/@excalidraw/excalidraw/api/props) - 可以传给 `Excalidraw` 组件的 `props`。
- [Children components(子组件)](/docs/@excalidraw/excalidraw/api/children-components) - 用于自定义 UI 的官方组件。
- [Utils(工具函数)](/docs/@excalidraw/excalidraw/api/utils) - 用于导出、还原等场景的工具和辅助函数。
