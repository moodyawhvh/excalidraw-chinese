# 开发

本页内容与 `@excalidraw/excalidraw` 包本身的开发相关。

## 示例应用

要启动使用 `@excalidraw/excalidraw` 包的示例应用,按以下步骤操作:

1. 安装依赖

   ```bash
   yarn
   ```

2. 启动示例应用

   ```bash
   yarn start:example
   ```

   默认浏览器会打开 [http://localhost:3001](http://localhost:3001)。

   该示例与 [CodeSandbox](https://codesandbox.io/p/sandbox/github/excalidraw/excalidraw/tree/master/examples/with-script-in-browser) 上的示例相同。

## 发布

### 创建正式版本

要发布下一个稳定版本,按以下步骤操作:

```bash
yarn release --tag=latest --version=0.19.0
```

你需要传入 `latest` 标签以及要发布版本的 `version`。该命令会完成发布到 NPM 前的准备工作,比如更新所有 `@excalidraw/*` 包的依赖、在 `CHANGELOG.md` 中生成新条目等。
