# 自定义样式

Excalidraw 使用 CSS 变量为部分组件设置样式。想覆盖这些变量,你需要在 `.excalidraw` 和 `.excalidraw.theme--dark`(深色模式变量)选择器上设置自己的值。

注意保证选择器优先级足够高,比如在前面加上你应用自身的选择器:

```css
.your-app .excalidraw {
  --color-primary: red;
}
.your-app .excalidraw.theme--dark {
  --color-primary: pink;
}
```

最常用的场景是自定义主色,覆盖下面这些变量即可:

- `--color-primary`
- `--color-primary-darker`
- `--color-primary-darkest`
- `--color-primary-light`
- `--color-primary-contrast-offset` — 比特 `--color-primary` 略深(浅色模式下)或略浅(深色模式下)的颜色,用于修复对比度问题(参见 [Chubb 错觉](https://en.wikipedia.org/wiki/Chubb_illusion))。未设置时会回退到 `--color-primary`。

完整变量列表见 [theme.scss](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/css/theme.scss),不过其中大部分变量没有覆盖的必要。

```css showLineNumbers
.custom-styles .excalidraw {
  --color-primary: #fcc6d9;
  --color-primary-darker: #f783ac;
  --color-primary-darkest: #e64980;
  --color-primary-light: #f2a9c4;
}

.custom-styles .excalidraw.theme--dark {
  --color-primary: #d494aa;
  --color-primary-darker: #d64c7e;
  --color-primary-darkest: #e86e99;
  --color-primary-light: #dcbec9;
}
```
```tsx live
function App() {
  return (
    <div style={{ height: "500px" }} className="custom-styles">
      <Excalidraw />
    </div>
  );
}
```
