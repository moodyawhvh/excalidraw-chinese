# 安装

**Excalidraw** 以组件形式导出,可直接嵌入你的项目中。

使用 `npm` 或 `yarn` 安装该包。

```bash
npm install react react-dom @excalidraw/excalidraw
# 或
yarn add react react-dom @excalidraw/excalidraw
```

:::tip

**如果不想等下一个稳定版本、想提前体验未发布的改动,可以使用 `@excalidraw/excalidraw@next`。**

:::

### 自托管字体

默认情况下,Excalidraw 会尝试从 [CDN](https://esm.run/@excalidraw/excalidraw/dist/prod) 下载所有用到的字体。

如果需要自托管,你必须把 `node_modules/@excalidraw/excalidraw/dist/prod/fonts` 文件夹里的内容复制到你存放静态资源的路径下(比如项目中的 `public/` 目录)。此时你还应把 `window.EXCALIDRAW_ASSET_PATH` 设置为同一个路径,例如资源在根目录时就设为 `/`:

```js
window.EXCALIDRAW_ASSET_PATH = "/";
```

或者,如果你的静态资源托管在 CDN 根路径下,可以这样写:

```js
// 原生 HTML
<head>
    <script>
        window.EXCALIDRAW_ASSET_PATH = "https://my.cdn.com/assets/";
    </script>    
</head>
```

或者,如果你希望路径基于 `location.origin` 动态设置,可以这样做:

```jsx
// Next.js
<Script id="load-env-variables" strategy="beforeInteractive" >
    { `window["EXCALIDRAW_ASSET_PATH"] = location.origin;` } // 也可以直接用 "/"!
</Script>
```

### Excalidraw 的尺寸

Excalidraw 会占满其容器的 _100%_ `width` 和 `height`,所以请确保渲染 Excalidraw 的容器尺寸不为零。
