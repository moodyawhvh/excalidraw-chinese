# 开发

## 在线沙箱(Code Sandbox)

- 打开 https://codesandbox.io/p/github/excalidraw/excalidraw
  - 可能需要先用 GitHub 登录并刷新页面
- 可以直接开始写代码,甚至能从那里直接发 PR!

## 本地安装

按照以下步骤,你就能在本地把项目跑起来,用于开发和测试。

### 环境要求

- [Node.js](https://nodejs.org/en/)
- [Yarn](https://yarnpkg.com/getting-started/install)(v1 或 v2.4.2+)
- [Git](https://git-scm.com/downloads)

### 克隆仓库

```bash
git clone https://github.com/excalidraw/excalidraw.git
```

### 安装依赖

```bash
yarn
```

### 启动服务

```bash
yarn start
```

现在打开 [http://localhost:3000](http://localhost:3000),用你顺手的编辑器开写即可。

## 协作功能

如果要在本地体验协作功能,你还需要在本地部署 [collab server](https://github.com/excalidraw/excalidraw-room)。

## 常用命令

### 安装依赖

```bash
yarn
```

### 运行项目

```bash
yarn start
```

### 用 Prettier 统一格式化所有文件

```bash
yarn fix
```

### 运行测试

```bash
yarn test
```

### 更新测试快照

```bash
yarn test:update
```

### 用 Prettier 检查代码格式

```bash
yarn test:code
```

### Docker Compose

如果不想折腾 Node.js 环境,可以用 docker-compose 在本地跑 Excalidraw。

```bash
docker-compose up --build -d
```

## 自托管

我们在 [excalidraw/excalidraw](https://hub.docker.com/r/excalidraw/excalidraw) 发布了包含 Excalidraw 客户端的 Docker 镜像。你可以用它在自己的域名下自托管客户端,部署到 Kubernetes、AWS ECS 等平台也没问题。

```bash
docker build -t excalidraw/excalidraw .
docker run --rm -dit --name excalidraw -p 5000:80 excalidraw/excalidraw:latest
```

该 Docker 镜像不含任何统计埋点和追踪类库。

**目前自托管实例不支持分享和协作功能。**

我们正在努力提供一套完整的自托管方案。
