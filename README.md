## 📖 项目简介

Excalidraw 是一个开源的虚拟手绘风格白板，让你像在纸上涂鸦一样轻松画出示意图、线框图和各种图示。它支持多人实时协作，并采用端到端加密保护内容安全。Google Cloud、Meta、Notion、CodeSandbox 等知名团队都在使用，在线体验地址：https://excalidraw.com

## ✨ 主要特性

- 💯 完全免费且开源（MIT 许可证）
- 🎨 基于画布的无限大白板
- ✍️ 独特的手绘风格图形
- 🌓 深色模式
- 🏗️ 高度可定制，可作为 npm 组件嵌入自己的应用
- 📷 支持插入图片
- 😀 支持图形素材库
- 🌐 支持多语言本地化（i18n），含简体中文
- 🖼️ 可导出为 PNG、SVG 或复制到剪贴板
- 💾 开放格式——绘图可保存为 `.excalidraw` JSON 文件
- ⚒️ 丰富的工具：矩形、圆形、菱形、箭头、线条、自由绘制、橡皮擦等
- ➡️ 箭头绑定与带标签箭头
- 🔙 撤销 / 重做
- 🔍 缩放与平移
- 📡 PWA 支持，可离线使用
- 🤼 实时协作 + 🔒 端到端加密
- 💾 本地优先，自动保存到浏览器
- 🔗 可生成只读分享链接

## 🚀 快速开始

**说明：** 以下步骤用于把 Excalidraw 作为 npm 包集成到你自己的应用中；如需本地跑起仓库做开发，请参阅官方[开发指南](https://docs.excalidraw.com/docs/introduction/development)。

使用 `npm` 或 `yarn` 安装组件包：

```bash
npm install react react-dom @excalidraw/excalidraw
# or
yarn add react react-dom @excalidraw/excalidraw
```

更多细节请查阅官方[文档](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/installation)。

不想写代码？直接打开 https://excalidraw.com 在线使用即可。

完整源代码与最新版本请访问原项目：https://github.com/excalidraw/excalidraw
